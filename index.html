Repository Analyser

AI-assisted technical review of public GitHub submissions — no cloning, no downloads.

§ Submission intake

Supports /tree/<branch>/<subfolder> links. Shareable: ?repo=owner/name&ps=PS-016

§ Analysis in progress

    Method

    The repository is read in-browser through the GitHub API and converted into a gitingest-compatible text digest: directory structure plus prioritised file contents (documentation, manifests, entry points, source, tests, notebooks with outputs).

    Two-layer evaluation

    Deterministic checks (documentation, tests, reproducibility, results evidence, secret leakage, commit timeline) are combined with an LLM review against the selected problem statement and an eight-criterion weighted rubric.

    Outputs

    An on-screen evaluation record, a printable PDF report with signature block, the full text digest, a JSON record, viva questions for the demo, and an interactive “ask the repository” assistant.

    AI-generated assessments are advisory. Scores support, and never replace, the judgement of the evaluation committee. Only public repositories are accessed; API keys remain in this browser.
